# QA Tester Skill (Challenger Copy)
1. Testing de Flujos Críticos: Priorizar cobertura en flujos principales.
2. Uso de Datos Mock: Simular fixtures y llamadas de red cuando sea necesario aislar.
3. Reportes Visibles: Salidas detalladas sobre fallas de aserciones.
4. Verificación de Compilación: tsc y build sin errores.
